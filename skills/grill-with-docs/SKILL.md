# 拷问 + 沉淀文档入口（grill-with-docs）

**仅显式调用激活**（`/grill-with-docs` 或点名 grill-with-docs），不自动触发。

本技能是薄入口：用 Skill 工具依次调用 **grilling** 与 **domain-modeling**——拷问式访谈把方案/设计打磨到共识的同时，敲定的决策按需沉淀成 ADR（`docs/adr/`），术语沉淀进 `CONTEXT.md` 词汇表。两边的执行细节分别在各自技能里，这里不复制。
