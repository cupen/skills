# 学习记录格式

学习记录存放在 `./learning-records/`，顺序编号：`0001-slug.md`、`0002-slug.md`……目录惰性创建：写下第一条时再建。

它们是教学版的 ADR：捕捉非显而易见的经验、关键洞见、以及用户自述的既有知识——这些将引导后续会话，并用于计算最近发展区。

## 模板

```md
# {学到了什么/确立了什么的一句话标题}

{1–3 句话：学到了什么（或确认了什么既有知识），以及它为什么影响后续教学。}
```

这就是全部格式。一条学习记录可以只有一段话。价值在于记录「**这现在已经知道了**」以及「**它如何改变接下来教什么**」，而不是填满小节。

## 可选小节

只在确有增量价值时加，多数记录用不上：

- **Status** frontmatter（`active | superseded by LR-NNNN`）：早先的理解被证伪并被取代时有用
- **Evidence**：用户如何展示了理解（答对了问题、完成了练习、援引了过往经验）。结论可能被重审时有用
- **Implications**：它为后续会话解锁/排除了什么。不明显时值得记

## 编号

扫 `./learning-records/` 取最大现有编号 +1。

## 何时写学习记录

任一条为真就写：

1. **用户展现了对某件不易之事的真实理解**：不只是接触过，而是有证据能正确使用该概念。这抬高了「接下来教什么」的地板。
2. **用户自曝既有知识**：「我已经会 X。」记下来，避免后续会话重教；同时记录其**深度**。
3. **一个误解被纠正**：用户此前信错了、现在明白为什么错。高价值：它们预示相关主题未来会踩的坑。
4. **使命因学习而偏移**：用户发现自己真正在乎的与原以为的不同。交叉链接 [[MISSION.md]] 并更新它。

### 什么不合格

- 仅仅是「讲过」的材料。讲过不等于学会，等证据。
- [[GLOSSARY.md]] 里已用术语定义简洁承载的内容。不要重复。
- 逐会话的活动流水账。学习记录不是日志：是决策级洞见。

## 取代

后来的记录与早先的矛盾（理解加深或被纠正）时，给旧记录标 `Status: superseded by LR-NNNN`，而不是删除。理解如何演化的历史本身就是有用信号。
