# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的规范语言。所有讲解、练习和学习记录都必须遵守它的术语。构建词汇表本身就是学习的一部分：把概念压缩成一句紧凑的定义，就是用户理解的证据。

## 结构

```md
# {主题} Glossary

{一两句话：本词汇表覆盖的主题。}

## Terms

**Hypertrophy（肌肥大）**:
肌肉经反复训练，由机械张力与代谢应激驱动的生长。
_Avoid_: Bulking, getting big

**Progressive overload（渐进超负荷）**:
随时间系统性地提高对肌肉的需求——经由负荷、容量或强度。
_Avoid_: Pushing harder, levelling up

**RPE (Rate of Perceived Exertion，自觉用力程度)**:
对一组动作吃力程度的 1–10 自评，10 = 力竭，8 = 还剩两次余量。
_Avoid_: Effort score, intensity rating
```

## 规则

- **用户理解了才收词。**词汇表是压缩知识的记录，不是给用户查学的词典。刚介绍的概念，等用户能正确使用再收进来。
- **要有立场。**同一概念有多个说法时，选定最好的一个，其余列为弃用别名。语言就是这样压缩的。
- **定义要紧。**一两句话。定义这个术语**是什么**，不是它做什么、怎么做。
- **定义内部使用词汇表自己的术语。**术语一旦收录，处处优先用它——包括其他定义里。这正是复杂术语日后更易理解的原因。
- 自然聚簇时**用小标题分组**（如 `## Anatomy`、`## Programming`）；术语同属一个内聚领域时平铺即可。
- **显式标记歧义。**某术语在业界用得随意时，写明本工作区的裁决：「在本工作区，『组（set）』一律指正式组；热身组单独记录。」
- **理解加深就修订。**第一周写的定义到第六周可能是错的。就地更新，不留过期条目。
